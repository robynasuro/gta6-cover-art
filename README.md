# Vice Cover Lab

An offline web app that turns two photos and a caption into GTA-style cover art: four multi-panel layouts, four sunset and neon colour grades, per-panel crop and position, bold Anton title lettering with a Pacifico subtitle, and PNG export in 1080x1080, 1080x1350 and 1920x1080. No network, no uploads — photos stay on your machine.

Run it with `node serve.ts`, then open http://localhost:8080.
